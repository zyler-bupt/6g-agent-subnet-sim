# Paper Exp.3 Business Elasticity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement four balanced business-change types, exact affected-scope sampling, four fair strategies, and the complete Exp.3 pilot and figures.

**Architecture:** Build a method-independent business-change snapshot on the shared modular DAG, compile one correct target state, and let each strategy select a permitted update scope before using the shared RuleDelta, transaction executor, and verifier.

**Tech Stack:** Python 3, asyncio, dataclasses, existing Stage 2/3 simulator, NumPy, Matplotlib, unittest.

**Spec:** `docs/superpowers/specs/2026-08-20-paper-experiments-finalization-design.md`

## Global Constraints

- Fixed scenario is 24 business Agents, 12 Gateways, and approximately 36 modular fork-join DAG edges.
- Change types are Agent Add, Agent Remove, DAG Edge Change, and QoS Update with balanced sampling.
- Samples enter `[10,20,30,40,50]%` buckets only after exact closure measurement.
- Methods are `proposed`, `netren`, `local_only`, and `full_rebuild` on identical snapshots.
- Local-Only may be fastest and smallest; Proposed is evaluated on minimal necessary scope and correctness.

```python
def test_change_is_generated_before_bucket_assignment(self):
```

```python
async def test_local_only_is_one_hop_and_does_not_escalate(self):
    plan = await plan_business_change(controller, stable, snapshot, "local_only")
    self.assertEqual(plan.scope_policy, "changed_object_plus_one_hop")
    self.assertEqual(plan.escalation_tier, 1)

async def test_netren_does_not_read_task_dependency_closure(self):
    with patch("src.controller.business_reconfiguration.exact_dependency_closure",
               side_effect=AssertionError("forbidden")):
        plan = await plan_business_change(controller, stable, snapshot, "netren")
    self.assertEqual(plan.scope_policy, "network_flow_resynthesis")

async def test_full_rebuild_changes_all_rules_while_proposed_uses_closure(self):
    proposed = await plan_business_change(controller, stable, snapshot, "proposed")
    full = await plan_business_change(controller, stable, snapshot, "full_rebuild")
    self.assertLessEqual(proposed.changed_rule_ids, full.changed_rule_ids)
    self.assertEqual(len(full.changed_rule_ids), len(stable.rules))
```

- [ ] **Step 3: Compile one shared correct target and permitted scopes**

Compile the post-change TaskSpec once per fresh method instance using the same
path/binding inputs. Proposed filters the shared target delta by exact closure,
then expands Tier-1/2/3 only after common feasibility rejection. Local-Only
uses changed object, one-hop neighbors, and attached Gateway only. NetRen
selects flows whose endpoint/QoS requirements changed and resynthesizes their
network configuration plus consistency repair. Full-Rebuild marks every
current rule as redeployed even if content is unchanged.

- [ ] **Step 4: Execute every plan through the common transaction verifier**

Use `TransactionExecutor` for stage, verify, activate, stable verify, and
rollback. Success requires new DAG validity, QoS, obsolete-rule removal, zero
stale rules, and stable verification. Compute unaffected disturbance against
the method-independent exact closure.
